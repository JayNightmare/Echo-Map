# Echo Map

A mobile application built with React Native and Expo.

## 📱 About

Echo Map is a cross-platform mobile application that runs on iOS, Android, and web platforms using React Native and Expo.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Expo Go app (for testing on physical devices)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/JayNightmare/Echo-Map.git
cd Echo-Map
```

2. Install dependencies:
```bash
npm install
```

### Running the App

Start the development server:
```bash
npm start
```

This will open Expo DevTools in your browser. From there, you can:

- **Run on iOS Simulator**: Press `i` (macOS only)
- **Run on Android Emulator**: Press `a` (requires Android Studio)
- **Run on Web**: Press `w`
- **Run on Physical Device**: Scan the QR code with the Expo Go app

Alternatively, you can run specific platforms directly:

```bash
npm run ios        # Run on iOS simulator (macOS only)
npm run android    # Run on Android emulator
npm run web        # Run on web browser
```
